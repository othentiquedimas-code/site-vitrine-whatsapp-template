# Site Vitrine WhatsApp — Template

Template de site vitrine Vue 3 réutilisable d'un client à l'autre, avec prise de commande 100 % via WhatsApp (sans paiement en ligne ni backend).

Pour le contexte complet (vision, primitives non négociables, points de personnalisation), voir le cahier des charges : [`docs/cahier-des-charges.md`](docs/cahier-des-charges.md). Les conventions techniques sont décrites dans [`docs/architecture.md`](docs/architecture.md), et les règles de travail des agents dans [`AGENTS.md`](AGENTS.md).

## Démarrage

```bash
npm install
npm run dev
```

Build de production :

```bash
npm run build
```
